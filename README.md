# OOP Project — Python Practice & Task Manager

A collection of Python object-oriented programming (OOP) exercises, API clients, and a CLI Task Manager with unit tests.

## Project Structure

- manager_tasks.py — Command-line Task Manager application for creating, viewing, and removing tasks with input validation.
- test_manager.py — Unit tests verifying task manager logic and error handling.
- Phone.py — Object-oriented class modeling smartphone properties and behavior.
- weather_checker.py — HTTP client for fetching real-time weather data via REST API.
- api_post.py — Script demonstrating HTTP POST requests and JSON payload handling.

## Technologies

- Language: Python 3
- Concepts: Object-Oriented Programming (OOP), Exception Handling, Unit Testing, REST APIs (GET/POST), JSON
- Tools: Git, GitHub, VS Code
